# Archive

Plans that were carried out, kept because they record *why* — not because they
describe how anything works now. Nothing here is current, and `docs:check`
deliberately does not check it.

- **[web-demo-plan.md](web-demo-plan.md)** — the original design of the web
  demo, shipped. Half of it argues for a Workers AI free tier that was never
  built; its closing section records the reversal to Claude plus a spend
  ceiling. That reversal was never measured, which is why this is archived
  rather than deleted: it is the only account of the decision, and it matters
  the day the demo has to run unbillable.
- **[bench-plan.md](bench-plan.md)** — the extraction benchmark plan, carried
  out. Superseded by [docs/extraction-speed.md](../extraction-speed.md), which
  explicitly retracts one of its findings: the claim that ~20% of files sent a
  blank page to two vision models turned out to be wrong.
